              PHONE BOOK APP
              --------------

PROJECT DESCRIPTION:
Phone Book App is used to store and manage contact details.

FEATURES:
1. Create a new contact.
2. Add multiple mobile numbers to same contact.
3. Add email and address.
4. Print all contacts.
5. Delete contact by name.
6. Find contact by name.
7. Edit contact details.
8. Save contacts in a file.
9. Load previous contacts when application starts.

DATA STRUCTURE:
Singly Linked List

FILE HANDLING:
Contacts are stored in phonebook.txt file.

COMPILATION:
Open terminal in project folder.

Run:
make

EXECUTION:
Run:
./phonebook

EXIT:
Select Q/q from menu.

CLEAN:
Run:
make clean
